Basic Array Creation
--------------------

Try running this code block to create 1D and 2D arrays:

.. code-block:: python

    import numpy as np

    # Create a simple 1D array
    arr_1d = np.array([10, 20, 30, 40])
    print("1D Array:", arr_1d)

    # Create a 2D matrix
    matrix = np.array([[1, 2], [3, 4]])
    print("2D Matrix:\n", matrix)
